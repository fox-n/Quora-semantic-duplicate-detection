# models/

Fine-tuned model weights go here (e.g. `sentence_transformer_duplicate_model/`, downloaded from Colab after running `notebooks/04_sentence_transformers.ipynb`).

Not committed to git — weight files are large binaries and don't belong in version control. This directory is `.gitignore`d except for this README and `.gitkeep`, so the folder itself still exists in a fresh clone.

To reproduce: run `notebooks/04_sentence_transformers.ipynb` in Colab and save the output here.
