# models/

Fine-tuned model weights go here (e.g. `sentence_transformer_duplicate_model/`, downloaded from Colab after running `notebooks/04_sentence_transformers.ipynb`).

Committed to git so `app.py` can be deployed directly from this repo on Streamlit Cloud, without a separate model-hosting step.

To reproduce from scratch: run `notebooks/04_sentence_transformers.ipynb` in Colab and save the output here.
